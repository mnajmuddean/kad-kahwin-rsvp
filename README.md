# 💌 Kad Kahwin Digital (Walimatul Urus)

Kad jemputan perkahwinan digital moden, elegan dan responsif (*mobile-friendly*), dioptimumkan untuk dihantar melalui WhatsApp / Telegram dan dibuka pada telefon pintar tetamu.

---

## ✨ Ciri-Ciri Utama

1. **Sampul Jemputan Beranimasi (*Opening Wax Seal Envelope*)**:
   - Animasi meterai lilin (*wax seal*) dengan butang sentuh "BUKA".
   - Alunan melodi romantis lembut dimainkan secara automatik apabila sampul dibuka.

2. **Muzik Latar Belakang (*Romantic Wedding Song*)**:
   - Lagu tema romantis pilihan anda ([`assets/song.mp3`](file:///C:/Users/USER/.gemini/antigravity/scratch/kad-kahwin-digital/assets/song.mp3)) dimainkan secara automatik apabila kad dibuka atau butang BUKA ditekan (dengan sokongan ulangan tanpa henti / *loop*).
   - Pemain audio terapung (*floating music player*) di sudut atas kanan untuk menjeda (*pause*) atau memainkan semula (*play*).
   - Dilengkapi fungsi sokongan sandaran (*failover*) ke sintesis audio web sekiranya pelayar web tetamu menyekat fail media luaran.

3. **Hitung Detik (*Live Countdown Timer*)**:
   - Mengira hari, jam, minit dan saat ke tarikh majlis perkahwinan secara masa nyata.
   - Pautan pintas **Tambah ke Google Calendar**.

4. **Atur Cara Majlis (*Event Timeline*)**:
   - Paparan jadual waktu yang kemas dari ketibaan tetamu sehingga majlis bersurai.

5. **Lokasi & Navigasi Terus**:
   - Pautan satu klik ke **Waze** dan **Google Maps**.
   - Butang **Salin Alamat** mudah untuk disalin ke aplikasi lain.

6. **Borang Pengesahan Kehadiran (RSVP) & Buku Ucapan**:
   - Tetamu boleh mengesahkan kehadiran (Hadir / Tidak Hadir), bilangan pax, dan menitipkan doa restu.
   - Ucapan dipaparkan secara langsung pada Buku Ucapan Tetamu.

7. **Hubungi Waris (Pautan Terus WhatsApp)**:
   - Butang WhatsApp untuk menghubungi bapa, ibu atau wakil keluarga.

8. **Salam Kaut / Hadiah Digital**:
   - Paparan nombor akaun bank dengan butang pantas "Salin Nombor Akaun".

9. **Kesan Visual Kelopak Bunga (*Floating Rose Petals Animation*)**:
   - Animasi kelopak bunga berguguran yang lembut menambah suasana romantik.

10. **Panel Suntingan Pantas (*Live Editor Modal*)**:
    - Tekan ikon pensel/gear ⚙️ di sudut kanan atas untuk menukar nama pengantin, ibu bapa, tarikh, dewan majlis, nombor WhatsApp, dan akaun bank secara terus.

---

## 🚀 Cara Menggunakan & Membuka

1. Buka fail [`index.html`](file:///C:/Users/USER/.gemini/antigravity/scratch/kad-kahwin-digital/index.html) menggunakan mana-mana pelayar web (Google Chrome, Microsoft Edge, Safari).
2. Tekan butang **💌 Buka** untuk melihat animasi dan mendengar alunan muzik.
3. Untuk mengubah maklumat kepada maklumat majlis anda, tekan ikon di sudut atas kanan dan masukkan maklumat sebenar anda.

---

## 🌐 Cara Kongsi Kepada Tetamu (Hosting Percuma)

Anda boleh meletakkan fail `index.html` ini dalam talian secara percuma menggunakan salah satu cara berikut:
- **Netlify Drop**: Seret sahaja folder ini ke [app.netlify.com/drop](https://app.netlify.com/drop) untuk dapatkan pautan laman web serta-merta.
- **Vercel** atau **GitHub Pages**.
- **Tiiny.host**: Muat naik fail `index.html` dan terus dapatkan *link* pendek untuk dikongsi dalam WhatsApp.
